# Goldak-Heat-source-APDL-for-Multiple-Layers-weld-Model
For Transient temperature Analysis
This is an APDL of Ansys 2024 R2 it is use as Moving heat source with feature like eKill and eAlive it also Animate the Welding process element by element to make simulation Realistic
Benefit of using this  model is that you only need on solid model for layers APDL will automatically slice the model into the layers defined in the code based on Dimension of layer Model.
Before using code identify the parameters needed for Simulation and update them into APDL Code
During meshing check the meshing does not interfere with code layer slicing
